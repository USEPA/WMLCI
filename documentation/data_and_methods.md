# Waste Management Life Cycle Inventory Model Assembler and Calculator (WMLCI) Data and Methods

WMLCI assembles life cycle inventory (LCI) data from [openLCA](https://dmap-data-commons-ord.s3.amazonaws.com/index.html#WMLCI/sourceData/) and [Federal LCA Commons](https://www.lcacommons.gov/) (FLCAC) sources, runs life cycle impact assessment (LCIA) using [Brightway](https://docs.brightway.dev/), and writes scenario-level results, saved as CSVs.

To generate LCIA results, users can either run an existing method YAML or create their own in the [`wmlci/methods/`](../wmlci/methods/) directory.
These method yamls contain all the information needed for a model run.
Model results can be generated by calling `run_bw_lca("<name>")`, where `"<name>"` is the name of the YAML file.

The package is initially being developed to replicate and improve on the EPA's Waste Reduction Model v16 [Excel tool](https://www.epa.gov/waste-reduction-model/versions-waste-reduction-model).
However, this package is also being developed to run LCIA results beyond greenhouse gas emission data, for other indicators such as those available in [EPA's TRACI](https://www.epa.gov/chemical-research/tool-reduction-and-assessment-chemicals-and-other-environmental-impacts-traci) for sustainability metrics such as acidification, eutrophication, smog formation and human health impacts. 
Results can also be generated for cumulative inventory indicators, which are direct totals of resource use and emissions and do not necessarily represent a potential environmental impact. 
Examples of inventory results include those within the [FEDEFL Inventory](https://www.lcacommons.gov/lca-collaboration/Federal_LCA_Commons/FEDEFL_Inv/datasets), which includes indicators such as energy and water sources. 

## Available Data Sources

Data sources used by WMLCI are defined under [`wmlci/extract/`](../wmlci/extract/) via YAML files.
These YAMLs contain instructions on how to retrieve the data.
Most sources are downloaded from the FLCAC via the API - see [`extract/README.md`](../wmlci/extract/README.md) for accessing and storing API keys. 
FLCAC datasets are already consistent with federal elementary flows ([FEDEFL](https://github.com/FLCAC-admin/fedelemflowlist)); WMLCI uses these elementary flows when harmonizing inventory and characterization factors.
The openLCA version of Waste Reduction Model v16 is stored and accessible on [EPA Data Commons](https://dmap-data-commons-ord.s3.amazonaws.com/index.html#WMLCI/sourceData/).

Running the methods will download and unzip any necessary raw data to a user's local `wmlci/data/source_data/`.

## Generating WMLCI Model Results

To run existing methods:

```python
from wmlci.lca import run_bw_lca

run_bw_lca("v16")
run_bw_lca("wmlci_pilot")
run_bw_lca("wmlci_pilot_smog")
```

---

Every method uses the shared runner in [`wmlci/lca.py`](../wmlci/lca.py) (`run_bw_lca`).
Differences between methods are defined in the specific YAML methods, such as the inventory source, LCIA method, parameters, and optional technosphere updates.

Results are written under `wmlci/data/results/`.

For result visualization, see [`examples/generate_graphics.py`](../examples/generate_graphics.py).

## Models

### v16

This model recreates the v16 Waste Reduction Model Excel tool results for 3 material–pathway combinations:

1. Incineration + plastic — MSW combustion of Mixed Plastics
2. Recycling + plastic — MSW recycling of Mixed Plastics
3. Organics + landfill — MSW landfilling of Food Waste (national-average LFG recovery, typical collection, national-average conditions)

**Inventory base:** Waste Reduction Model v16 openLCA data that is stored on [EPA’s Data Commons](https://dmap-data-commons-ord.s3.amazonaws.com/index.html#WMLCI/sourceData/), then edited to the relevant material-pathway data via [`waste_reduction_model_v16_pilot.yaml`](../wmlci/extract/waste_reduction_model_v16_pilot.yaml).

**Config:** [`v16.yaml`](../wmlci/methods/v16.yaml)

- LCIA: [`ipcc_gwp`](../wmlci/extract/ipcc_gwp.yaml) method `IPCC` / `AR4-100`
- Functional unit: 1 US short ton

---

### wmlci_pilot

This method builds off the original v16 Waste Reduction Model openLCA data and improve emission estimates by:

1. Updating LCIA to the most recent IPCC GWP (AR6-100)
2. Replacing transportation with non-truncated (FLCAC / USLCI) data
3. Improving electricity background data (US electricity baseline)
4. Improving plastics recycling / manufacturing pathways (USLCI resin/pellet datasets)

**Inventory base:** The same as `v16.yaml`: Waste Reduction Model v16 openLCA data that is stored on [EPA’s Data Commons](https://dmap-data-commons-ord.s3.amazonaws.com/index.html#WMLCI/sourceData/), then edited to the relevant material-pathway data via [`waste_reduction_model_v16_pilot.yaml`](../wmlci/extract/waste_reduction_model_v16_pilot.yaml).

**Config:** [`wmlci_pilot.yaml`](../wmlci/methods/wmlci_pilot.yaml)

- LCIA: [`ipcc_gwp`](../wmlci/extract/ipcc_gwp.yaml) method `IPCC` / `AR6-100`
- Functional unit: 1 US short ton
- Background data updates/replacements:
  - [`msw_landfilling_fw_LfgNtlAvg_CollecTyp_CondNtlAvg.yaml`](../wmlci/technosphere_updates/msw_landfilling_fw_LfgNtlAvg_CollecTyp_CondNtlAvg.yaml)
  - [`msw_combustion_mixed_plastics.yaml`](../wmlci/technosphere_updates/msw_combustion_mixed_plastics.yaml)
  - [`msw_recycling_mixed_plastics.yaml`](../wmlci/technosphere_updates/msw_recycling_mixed_plastics.yaml)
- Secondary sources pulled in by those updates (via [`extract/`](../wmlci/extract/)):
  - [`uslci.yaml`](../wmlci/extract/uslci.yaml)
  - [`us_electricity_baseline.yaml`](../wmlci/extract/us_electricity_baseline.yaml)
  - [`heavy_equipment_operation.yaml`](../wmlci/extract/heavy_equipment_operation.yaml) (landfilling)

### wmlci_pilot_smog

This method takes a similar approach `wmlci_pilot`, in that this method builds off `waste_reduction_model_v16_pilot.yaml`. 
However, this model assesses TRACI 2.2 smog, rather than GWP. 

As the Waste Reduction Model does not evaluate smog, the model data was updated by integrating data from additional sources.

1. Integrate [SwolfPy](https://swolfpy-project.github.io/) waste-to-energy (WTE) air emission inventory for mixed-plastics combustion
2. Applying TRACI 2.2 Smog formation LCIA (kg O₃ eq) rather than IPCC GWP
3. Includes the FLCAC technosphere updates for transport, electricity, and plastics recycling / manufacturing defined in `wmlci_pilot`
4. Incorporates additional FLCAC technosphere updates that are not included in `wmlci_pilot` (lime / ammonia / activated carbon)

**Inventory base:** Waste Reduction Model v16 openLCA data combined with SwolfPy WTE JSON-LD via [`waste_reduction_model_v16_pilot_w_swolfpy.yaml`](../wmlci/extract/waste_reduction_model_v16_pilot_w_swolfpy.yaml) ([`integrate_swolfpy_data`](../wmlci/integrate_swolfpy_data.py)).

**Config:** [`wmlci_pilot_smog.yaml`](../wmlci/methods/wmlci_pilot_smog.yaml)

- LCIA: [`traci_2_2`](../wmlci/extract/traci_2_2.yaml) method for `Smog formation`
- Functional unit: 1 US short ton
- Same three material–pathway scenarios as `v16` / `wmlci_pilot`
- Background data updates/replacements:
  - [`msw_landfilling_fw_LfgNtlAvg_CollecTyp_CondNtlAvg.yaml`](../wmlci/technosphere_updates/msw_landfilling_fw_LfgNtlAvg_CollecTyp_CondNtlAvg.yaml)
  - [`msw_combustion_mixed_plastics_w_air_emissions.yaml`](../wmlci/technosphere_updates/msw_combustion_mixed_plastics_w_air_emissions.yaml)
  - [`msw_recycling_mixed_plastics.yaml`](../wmlci/technosphere_updates/msw_recycling_mixed_plastics.yaml)
- Secondary sources pulled in by those updates (via [`extract/`](../wmlci/extract/)):
  - [`uslci.yaml`](../wmlci/extract/uslci.yaml)
  - [`us_electricity_baseline.yaml`](../wmlci/extract/us_electricity_baseline.yaml)
  - [`heavy_equipment_operation.yaml`](../wmlci/extract/heavy_equipment_operation.yaml)
  - [`waste_reduction_model_v16_pilot_w_swolfpy.yaml`](../wmlci/extract/waste_reduction_model_v16_pilot_w_swolfpy.yaml)

## Future Method Considerations

### SwolfPy flows without TRACI 2.2 characterization factors

Two SwolfPy emission mappings do not align with TRACI 2.2 mappings and therefore do not contribute to TRACI impact scores:

| Flow | UUID |
|------|------|
| Chlorinated dioxins and furans -- 2,3,7,8 congeners only | `16c208f1-371c-3e27-a0ca-ee18b01d862e` |
| Hydrocarbons | `6a8ca31c-ede5-38b1-8c30-2d50fb499a55` |

### Scope of plastics manufacturing transport

v16 includes transport of manufactured products to retailer (497 miles). 
USLCI resin and pellet data generally represent manufacturing to the plant gate. 
`wmlci_pilot` does not add a separate retail-transport step on top of the USLCI replacements.

### Ash transport from combustion

Ash handling was not updated in the `wmlci_pilot` methods the Waste Reduction Model v16 openLCA methodology. 
In v16, ash transport assumes:  
- 1 short ton of ash transported to landfill per 1 short ton of combusted material.  
- The modeled transportation distance is unclear.
